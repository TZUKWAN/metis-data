# 全产品模拟用户验收 — 测试清单（Computer Use 真实操作）

产品：Metis Data 桌面端（Electron + 本地后端 http://127.0.0.1:8300）
启动方式：关闭已运行后端 → 直接启动 Electron（测启动屏→自动拉起后端→进入 UI）

## 模块清单
1. 启动链路：启动屏 → 后端健康 → 自动导航 UI → 连接状态点变绿
2. 顶栏：品牌 / 连接状态点 / ＋新会话 / ⚙设置
3. 聊天面板：空状态文案、3 个建议按钮、消息气泡（用户/助手）、错误气泡
4. 输入区：占位符、空输入禁用发送、输入启用、Enter 发送并清空、Shift+Enter 换行、
   超长输入(>2000字)、快速连续提交（sending 防抖）、自动增高
5. 任务状态条：阶段文案（理解/规划/搜索/获取/合成）、进度条、停止按钮真取消
6. 结果面板：空态文案、计数头、结果卡（标题/状态徽标/来源/信任与许可徽标/理由）
7. 预览：FOUND→metadata 视图；READY→真实数据表格；FINAL→最终表；返回列表
8. 下载：FOUND→触发获取链（POST download）→READY 状态流转；READY→文件保存
9. 导出：CSV / XLSX / PARQUET 按钮
10. 设置弹窗：打开、已保存登录列表、隐私说明、关闭
11. Auth 弹窗（可达路径内）：需要登录的来源出现时 → 我已完成(probe) / 跳过该来源 / 打开登录窗口
12. 浏览器监视浮层（经 Auth 弹窗或可达路径）
13. 刷新恢复：Ctrl+R 后消息+结果+任务状态恢复
14. 新会话隔离：清空 UI、cid 更换、旧结果不可见
15. 调试抽屉：Ctrl+Shift+D 开/关
16. 探索性：取消进行中任务、同一消息重复提交、空格输入、纯符号输入、
    窗口最大化/还原布局、快速切换预览/列表
17. 持续观测：后端日志 5xx、页面无响应、布局遮挡/滚动异常、按钮无响应
